# Inspectra Roadmap

## Phase 1: Core Foundation ✅ (v0.1.0)

- [x] Process management (list, attach, find)
- [x] Memory read/write operations
- [x] Memory region queries
- [x] Basic scanner engine
- [x] Pattern matching (AOB)
- [x] Pointer scanning basics
- [x] Code patching utilities
- [x] Python bindings foundation
- [x] Documentation and examples

## Phase 2: Enhanced Scanning (v0.2.0)

**Target: Q2 2025**

- [ ] Optimized scanning with SIMD
- [ ] Advanced scan types (increased, decreased, unknown initial)
- [ ] Range scanning
- [ ] Fuzzy value matching
- [ ] Result filtering and sorting
- [ ] Scan history and sessions
- [ ] Snapshot comparison

## Phase 3: Advanced Pointer Analysis (v0.3.0)

**Target: Q3 2025**

- [ ] Improved pointer chain discovery
- [ ] Static vs dynamic address detection

- [ ] Data type inference
- [ ] Pointer path persistence
- [ ] Offset visualization
